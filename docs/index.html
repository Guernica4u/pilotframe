Pilotframe

An unofficial rebuild of Titanfall (2014, PC) in Rust and Bevy. It runs from your own copy of the game: every map, model, texture and script is read from your EA install, and none of it is in this project. Not affiliated with, endorsed by, or connected to Electronic Arts or Respawn Entertainment.

Questions

Once the script engine is done, is the whole game "decompiled" and easy to add?

Not all of it. It helps to split the game into layers:

Scripts

HUD, weapon behaviour, game modes, menus. These run as they are, from your install. Once their engine functions exist, they behave like the original by construction.

client.dll

The game's client code. It has been decompiled for reference, but nothing from it is copied: each function is read, written up, and rewritten in Rust. About 1,900 script functions, ported one by one.

Server

The PC game never shipped its server code (matches ran on Respawn's servers). Its scripts are in the install, but the engine functions under them have to be worked out from the client's matching code and from how the scripts use them.

Engine

Rendering, physics, animation, sound, particles, networking. These are Bevy plus our own code, checked against the real game by screenshots and recordings.

So the script engine removes the biggest guesswork (how the HUD, guns and modes behave is in the scripts), and the remaining work is steady porting rather than reinventing. It's still a lot of work, and the server side is the hardest part.

Do I need the game?

Yes. Pilotframe ships no game files. Point it at your own EA install of Titanfall (final patch). Without it, only a grey test map runs.

Is any original code in here?

No. All code is written for this project, under GPL-3.0. The game's files are read from your install at run time and never copied into the project or its releases.
