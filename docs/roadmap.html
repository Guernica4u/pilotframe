Pilotframe Roadmap

A from-scratch Rust and Bevy rebuild of the 2014 mech shooter, using assets from each player's own PC or Xbox 360 discs. Milestones run in order. Two tracks can be worked on at the same time.

When can I boot it? Goal: boot to the rebuilt menu, pick Colony, and walk it with real pilot movement. Path: M2 → M3 → audio → M4 → M5 → setup screen + menu. Estimate: roughly 3–6 weeks of sessions after M2 starts (Thu 2026-10-08), so around mid-to-late November 2026. A plain, untextured fly-through of Colony should come within the first week.

Two tracks, two people

Track A · Game files to maps

Reads the disc and gets the original maps on screen. Needs a Titanfall 360 dump.

  1. M2 raw map geometry
  2. M3 textured fly-through
  3. Then models and animations for M6–M8

Track B · Movement sandbox

Builds the pilot controller on a homemade test map. Needs no game files, so it can start today.

  1. M4 walk with collision on a greybox map
  2. M5 faithful pilot movement
  3. Merges with Track A when M3 lands

Suggested split: you take Track A, your friend takes Track B. Each track works on its own branch and merges through pull requests.

DoneTrack A

  • All 18 packs fully unpack, zero failures
  • Found BSP, models, VTFX textures, animations, entities
See the maps
M2

Draw Colony's raw geometry (PC)

NextTrack A1–3 days · up to 2 weeks

Colony's shapes from the PC discs appear in a Bevy window that you can fly around in. No textures yet.

  • Checked the PC discs: one ZIP split over 3 discs, VPKs stored with Deflate, so first launch unpacks them into a data/ cache
  • DLC: all 3 packs (9 maps) present with their index files
  • ZIP reader across the 3 disc images + Deflate unpack
  • Respawn VPK reader + LZHAM decompression
  • Decode Colony's vertex, index and mesh lumps (rBSP v29)
  • Add Bevy to the project, pinned to the latest stable version
  • Viewer app with a fly camera, flat-shaded lobby on screen
  • Later: match the 360 version's lumps to the PC ones
M3

Fly through a full textured map

PlannedTrack A1–2 weeks · up to 2 months

Colony looks like Colony: textures, lighting, props and sky. The game loads only from your local converted cache.

  • VTFX textures: untile the Xbox 360 layout, swap DXT byte order
  • Work out the streaming texture sets (main.st1/.st2), still undocumented
  • Materials from text definitions
  • Lightmaps, static props (models), skybox
  • pf-setup command-line tool: ISO in, cache out
Be a pilot
M4

Walk the map with collision

PlannedTrack Bdays · up to 2 weeks

Run around with gravity, slopes and steps, and never fall through the floor. Keyboard, mouse and controller all work.

  • Homemade greybox test map (no game files needed)
  • Capsule character controller on a fixed simulation tick
  • Input actions for keyboard/mouse and controller
  • Collision from real map data once M3 is in
M5

Faithful pilot movement

PlannedTrack B2–4 weeks · then ongoing tuning

Sprint, double jump, wall-run, wall-hang, slide and air control, each matched to measurements from the 360 version.

  • Collect 360 gameplay clips from YouTube (you pick, I analyse frame by frame)
  • Read numeric settings files from the disc as data
  • Every value logged with its source and error margin
  • Side-by-side comparison against the clips

Open research on the side

Entry namesPacks store 64-bit hashes, not file names. Common hash functions didn't match. Not blocking.
Streaming texturesmain.st1/.st2, about 2.2 GB, Bluepoint's own format. Blocks M3.
Animations (BPAN)The biggest content type in every pack. Needed for titans and pilots.
AudioWwise packages, which the community already documents. Low priority until M8.
