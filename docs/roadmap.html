Current focus

R5 · Script engine

The HUD, minimap, weapon behaviour, game rules and menus are scripts in the install. Running them in our own interpreter gives the exact behaviour without hand-copying anything, and nothing from the game is ever shipped.

  1. ✓
    Inventory

    All 1,615 engine functions scripts can call, the load order (168 client files, 83 UI files) and the ~97 engine callbacks.

  2. ✓
    Parser

    Reads all 481 game scripts, with the same error messages as the game.

  3. ✓
    Oracle

    146 test cases run in the real game. Our parser agrees with the game on every one.

  4. ✓
    The interpreter's internals

    Read from launcher.dll: the string hash and table layout (our foreach order matches the game's), error chaining, argument rules, the sort.

  5. ✓
    Run scripts

    Our compiler and VM. All 146 oracle cases print exactly what the game printed, and all 481 game scripts compile.

  6. 6
    Threads and signals

    thread and wait work. Next: the game's own thread functions in launcher.dll (SpinOff, Signal, WaitSignal, EndSignal, OnThreadEnd), which _threads.nut builds on.

  7. 7
    First milestone: a gun and the HUD

    Run the R-101C's weapon script and cl_main_hud.nut with their engine functions. Then shooting and the HUD start for real.
